# Three-way round robin implementation

The schedule consists of D3, F1B4 and F2B8 playing all three distinct matchups in both color orders. Every pairing uses the same ten previously unused seed pairs from 6,100,000 through 6,100,019. In trial `i`, Black receives `6100000 + 2*i` and White receives the next integer. The game ends on its natural terminal condition or stops at 20,000 plies with an unresolved result. A ply is one placement followed by the board evolution. The per-decision successor ceiling is 100,000.

The first segment used the previously validated [deferred-board build](../budgeted-search-20k-provenance/deferred-boards/README.md). The second segment used `exact_search.cc` for the same elimination search, with canonical Dart state hashes, tie seeds, game transitions and checkpointing. `boundaries.json` contains the exact last ply and state hash of each existing game at the switch. `build.json` records executable identities. This change affects time per move, so the combined timing log is unsuitable for a controlled latency comparison.

The compiled kernel orders successors by utility and row-major coordinate, deduplicates exact cell patches, stops at the original budget boundary, and calculates the same alpha-beta and cache counters. Its final-ply shortcut uses the exact utility of sorted terminal or horizon leaves. On that ply the first child already attains the node value. The shortcut counts a single child if it causes a strict cutoff and all retained children otherwise.

The kernel reproduced the complete non-time decision records for 120 historical reference cases and 767 sampled choices from the first segment of this tournament. All 17 search and tournament tests passed. The original agent reproduced 36 actual choices immediately after the switch. A counterbalanced benchmark measured about 20 times faster search on the 36 fixed test decisions. The final report links the complete canonical trajectory audit and fresh decision sample.

To rebuild on macOS, use Dart 3.12.2 and a separate checkout of the revision in `build.json`. Apply the screen's `immutable-board-cache.patch`, then `deferred-boards/incremental.patch`, then `dart-adapter.patch` using `git apply`. Compile `exact_search.cc` with `clang++ -O3 -std=c++17 -dynamiclib exact_search.cc -o libexactsearch.dylib`. In `packages/game_ai`, resolve dependencies and compile `bin/budgeted_search_tournament.dart` with `dart compile exe`. Set `LIFE_SEARCH_LIBRARY` to the absolute path of the compiled library when launching the runner with the [study configuration](../budgeted-search-three-way-20k-config.json). The formatted C++ source reproduced the exact running library byte for byte on this machine.
